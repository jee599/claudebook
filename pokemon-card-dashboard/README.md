# 🎴 포켓몬 일본판 카드 시세 대시보드

일본판(日本版) 포켓몬 카드의 **전체 목록 · 현재 시세 · 지난 1년 시세 변화 · 적정 매수가(싸게 사는 가격) · 상승 확률 · 현재 가치(저평가/고평가)** 를 한눈에 보여주는 풀스택 대시보드입니다.

> ⚠️ **데모용 샘플 데이터입니다.** 시세는 카드 메타데이터를 기반으로 생성한 모의 값이며, 실제 매매 판단의 근거로 사용하지 마세요. 실제 API(카드러시·매물 스크래핑 등) 연동 시 `data/cards.js` 와 `src/seed.js` 만 교체하면 됩니다.

## 빠른 시작

```bash
cd pokemon-card-dashboard
npm install          # 의존성 설치 (better-sqlite3, express, chart.js)
npm run seed         # 샘플 카드 + 1년치 시세를 SQLite에 시딩 (최초 1회, 자동 실행되기도 함)
npm start            # 서버 실행 → http://localhost:3000
```

브라우저에서 `http://localhost:3000` 접속.

## 주요 기능

| 기능 | 설명 |
|------|------|
| **카드 목록** | 일본판 포켓몬 카드 24종(샘플). 등급/확장팩/발매연도 표시 |
| **현재 시세** | 엔(¥) + 원(₩) 환산 동시 표시 |
| **1년 시세 변화** | 카드별 스파크라인 + 상세 모달의 365일 라인 차트 |
| **적정가(현재 가치)** | 중기 이동평균 기반 공정가치. 현재가와 비교해 **저평가 / 적정 / 고평가** 판정 |
| **싸게 사는 가격** | 최근 120일 분포 하단부(10~30 분위)로 추천 매수 구간·목표가 산출 |
| **상승 확률** | 모멘텀 + 평균회귀 + 장기추세를 로지스틱으로 합성한 0~100% 확률 |
| **종합 추천** | 매수 적기 / 분할 매수 / 관망 / 매도 고려 |
| **필터·정렬** | 검색, 등급/추천 필터, 상승확률·상승률·현재가·저평가순 정렬, "지금 저렴한 카드만" 토글 |

## API

| 엔드포인트 | 설명 |
|-----------|------|
| `GET /api/cards` | 전체 카드 + 지표 + 스파크라인용 축약 시세 |
| `GET /api/cards/:id` | 카드 단건 + 1년치(365일) 전체 시세 |
| `GET /api/summary` | 대시보드 상단 요약 통계 |

## 지표 산출 방식 (요약)

- **시세 생성**: 카드 id를 시드로 한 결정론적 PRNG. 장기추세 드리프트 + 일간 변동성 + 완만한 사이클 + 간헐적 급등락 이벤트를 섞은 기하브라운운동 변형. (같은 카드는 항상 같은 시세 → 재현 가능)
- **적정가**: 120일 이동평균
- **가치 평가**: `현재가 / 적정가` 비율 → <0.92 저평가, ~1.08 적정, >1.08 고평가
- **상승 확률**: `σ(3.5·모멘텀 + 1.8·평균회귀 + 0.6·장기추세)` (7~93%로 클램프)
- **싸게 사는 가격**: 최근 120일 가격 분포의 25분위(매수 목표가), 10~30분위(매수 구간)
